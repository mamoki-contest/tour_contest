# 지역 방문 규모 지도와 관광지 관심도 정렬의 분리

상태: accepted

ADR-0004의 지역 방문 규모와 중심관광지 순위를 합산한 `한사나다 인기도`는 사용하지 않는다. 지역 방문 규모는 현재 지도 단계의 행정구역 색상에만 사용하고, 관광지 목록은 현재 지도 탐색 범위 안에서 관광지 단위 관심도를 기준으로 `인기 많은 순`과 `덜 알려진 순`을 제공하며, 방문 혼잡도 예측은 장소 상세의 날짜 선택 정보로 독립해 제공한다.

관광지 관심도는 티맵 관광지 관심지점 집계처럼 장소 단위의 과거 관심 행동을 사용하므로 실제 방문객 수나 실시간 혼잡도로 표현하지 않는다. 관심도 결측은 낮은 관심도로 간주하지 않고 미산정으로 분리하며, 지도 색상과 목록 정렬에는 각각 별도의 범례·기준 시점·데이터 출처를 표시한다.

강원도 범위의 MVP에서는 공개 API로 확인되는 시·군 방문 규모를 색상으로 제공하고, 읍·면·동 단계는 문서화된 무료 데이터가 확보될 때까지 관광지 마커와 범위 내 목록만 제공한다. 지도 이동 후 사용자가 `이 지도 영역에서 검색`을 실행할 때 목록 범위를 갱신하며, 향후 행정동 방문 규모 데이터가 확보되면 같은 구조에 하위 색상 단계를 추가한다.
