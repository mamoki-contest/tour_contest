# 탐색 홈과 나만의 지도의 분리

상태: accepted

웹 MVP의 시작 화면은 개인 컬렉션 지도가 아니라 관광지 발견을 위한 `탐색 홈`으로 한다. 기본 상태는 강원도 전체·무테마·날짜 미정·인기 많은 순이며, 사용자는 덜 알려진 순으로 전환하거나 검색·테마·날짜 조건을 필요할 때 적용한다.

`나만의 지도`는 개인 컬렉션을 확인하는 별도 주요 메뉴로 유지한다. 카드의 상시 저장 동작, 저장 직후 지도 이동 안내, 저장 개수 표시와 탐색 홈의 저장 장소 미리보기로 두 화면을 연결하고, 저장 장소가 없을 때는 빈 지도 대신 탐색으로 돌아가는 진입점을 제공한다. 이 선택은 재방문자의 컬렉션 접근보다 첫 방문자의 즉시 탐색을 우선하되, 컬렉션이 보조 기능으로 묻히는 위험을 지속적인 저장 연결로 완화한다.
