# 웹 MVP와 분리 배포

상태: accepted

한사나다 MVP는 네이티브 모바일 앱 대신 모바일 우선 반응형 웹으로 제공한다. 프론트엔드는 TypeScript와 React Router를 사용해 Vercel에 배포하고, 백엔드는 Java 21과 Spring Boot를 사용해 AWS에 배포하며 MySQL에는 관광 데이터 정규화 결과, 대체지 큐레이션과 외부 API 캐시를 보관한다.

회원가입과 계정 동기화는 MVP에서 제외하고 개인 컬렉션은 현재 브라우저와 기기에 보관한다. 이 선택은 공모전 일정 안에서 핵심 여정을 완성하고 첫 사용의 인증 마찰을 없애는 대신, 기기 간 동기화·재설치 복구·사용자 북마크 집계를 후속 범위로 미룬다.

분리 배포로 인해 프론트엔드와 백엔드 사이의 허용 출처를 명시해야 하며, 향후 실시간 유동인구 데이터는 기존 방문 혼잡도 예측 및 현재 접근 혼잡과 구분된 공급자로 백엔드에 추가한다.
