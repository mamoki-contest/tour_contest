# 혼잡 신호의 역할 분리

상태: accepted

한사나다는 성격과 시간 범위가 다른 혼잡 신호를 하나의 절대 혼잡도 점수로 합치지 않는다. 지역 방문 규모는 덜 방문된 시·군을 찾는 지역 단위 발견 신호, 방문 혼잡도 예측은 한 장소의 향후 30일을 비교하는 날짜 선택 신호, 현재 도로·주차 정보는 당일 접근 여건, 향후 도입할 실시간 유동인구는 현재 인파 혼잡으로 각각 독립해 사용한다.

날짜 확정 탐색에서는 선택일이 각 장소 자체의 예측 범위에서 어느 수준인지 제시하고, 날짜 유연 탐색에서는 장소별로 상대적으로 한산한 예상일을 제안한다. 지역 방문 규모나 현재 접근 혼잡을 미래 특정일의 사람 수로 해석하지 않는다. 이 선택은 단순한 장소 간 혼잡도 순위를 포기하는 대신 데이터가 실제로 표현하는 범위를 지키고, 향후 실시간 유동인구 공급자를 기존 신호와 혼동 없이 추가할 수 있게 한다.
