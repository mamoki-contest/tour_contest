# 지원 테마와 일반 검색의 분리

상태: accepted

한사나다의 테마 탐색은 MVP에서 검증 가능한 5~8개의 지원 테마를 중심으로 제공하고, 동의어와 오타는 가능한 경우 지원 테마로 정규화한다. 지원되지 않는 자유 입력은 관광 정보 키워드 기반 일반 검색으로 처리하되, 화면과 데이터 모델에서 지원 테마 결과와 명확히 구분한다.

일반 검색 결과에는 테마 적합성, 대체지 추천 또는 숨은 명소라는 보증을 붙이지 않으며 결과가 부족할 때는 억지 후보 대신 가까운 지원 테마를 제안한다. 이 선택은 지정 테마만 제공하는 좁은 탐색과 모든 키워드를 동일한 추천으로 취급하는 불안정한 탐색 사이에서, 핵심 사례의 신뢰도와 자유 검색의 범위를 함께 확보한다.
