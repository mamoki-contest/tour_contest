# 강원도 관광지의 양방향 인기도 탐색

상태: superseded by ADR-0006

무테마 탐색은 덜 방문된 지역만 추천하는 흐름이 아니라, 강원도 관광지를 `인기 많은 순`과 `덜 알려진 순`으로 뒤집어 볼 수 있는 하나의 목록으로 제공한다. 기초지자체 중심관광지 순위는 지역 내부 순위이므로 그대로 합치지 않고, 정규화한 지역 방문 규모와 지역 내 중심관광지 순위를 결합한 서비스 자체 지표인 `한사나다 인기도`를 사용한다.

두 원천 데이터와 추천 자격을 모두 갖춘 장소만 인기도 정렬에 포함하고, 데이터가 부족한 장소는 낮은 인기도로 간주하지 않고 미산정 상태로 분리한다. 인기도는 과거·누적 관점의 발견 신호이고 방문 혼잡도 예측은 선택한 장소의 날짜 비교 신호이므로, 정렬 명칭에 `혼잡한 순`이나 `한산한 순`을 사용하지 않는다. 날짜 미정이면 장소별 한산 예상일을, 날짜 확정이면 선택일의 장소 내부 상대 수준을 인기도와 별도로 제시한다.
